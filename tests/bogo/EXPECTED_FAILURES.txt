# 2026-09-14 UPDATE (chore/bogo, verify-callback flags): the shim now
# implements -verify-fail / -expect-verify-result / -use-custom-verify-callback /

#  (a) CertificateVerificationFail-{Client,Server}-*-TLS-Sync* (32): with
#      -verify-fail the handshake is refused as required, but BoGo's Sync

#      legacy callback, certificate_unknown (46) for the custom one. We send

#  (d) *-MatchNone-* (12): no configured credential fits the CertificateRequest.
#      RFC 8446 4.4.2 / RFC 5246 7.4.6 say the client MUST then send an empty
#      Certificate, which we do; BoringSSL aborts with handshake_failure and
#      BoGo pins that. Intentional deviation.
#  (e) Client-ClientCertificateTypes-ECDSA-Ed25519-* (4): Ed25519 client

#  (f) Client-SignatureAlgorithmECDSACurve-TLS-TLS12 (1): a P-384 client key

#      be independent, our signer binds P-384 to SHA-384. Gap.

# 2026-09-14 UPDATE 5 (chore/bogo, one-off investigation): 1462 -> 1464
# passing, 74 -> 70 known failures. Two were REAL BUGS:
#  - CertificateRequestInResumption-TLS13: the client silently dropped any
#    TLS 1.3 ticket longer than 256 bytes (Max_Ticket_Len). Servers embed the
#    client's certificate chain in the ticket after mutual authentication
#    (OpenSSL 3: 208 bytes plain, 1072 with a client cert; Go about 830), so
#    no mTLS session ever resumed. Cap raised to 2048, matching TLS 1.2.
#  - Resume-Server-NoPSKBinder-SecondBinder: after HelloRetryRequest the
#    server replaced every CH2 PARSE error with illegal_parameter; a
#    truncated binders list is decode_error in CH2 as in CH1. The CH1/CH2
#    consistency checks keep illegal_parameter.
# Two moved to the out-of-scope skip list: {Client,Server}-VerifyDefault-
# Ed25519-TLS13 assert BoringSSL's default verify-preference table (Ed25519
# off unless enabled); SPARKTLS accepts Ed25519 by default, as browsers do.
# Still open and understood: (f) above, the TLS 1.2 ECDSA hash/curve
# decoupling, which needs the P-384 signer to take a SHA-256 digest and the
# scheme matcher to relax the curve in TLS 1.2 mode.
